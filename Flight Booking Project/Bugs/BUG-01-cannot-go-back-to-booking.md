# Booking Flight — User can't go back to booking page

**Related Jira issue:** FBA-1
**Priority:** Low

## Steps to reproduce
1. Login as valid user
2. Book a flight with all valid data
3. Pay for the flight

## Expected
There should be a button to return and book a new flight.

## Actual
User is stuck in the flight information page and can't go back.

## Severity
Low
