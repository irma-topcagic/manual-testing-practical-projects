## Manual Testing — Practical Projects

A collection of manual testing projects, each covering a different web application from end to end — writing test scenarios and test cases, executing them, and documenting the bugs found.

### Projects

**Flight Booking Project**
Testing the full booking flow of a flight reservation app: selecting a flight, entering passenger details, and completing payment. Includes valid/invalid test scenarios, detailed test cases, and bug reports for validation issues found in the booking flow.

**To Do List Project**
CRUD testing (Create, Read, Update, Delete) of a simple to-do list app, including edge cases like SQL injection input, empty fields, and cross-browser checks. Includes test scenarios and bug reports.

### Tools

- **Jira + Zephyr Scale** — test case management, test execution tracking, and defect linking
- **Trello** — test scenario checklists and bug report cards
